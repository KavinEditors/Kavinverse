# Kavinverse

A modern dark-themed developer portfolio built with **HTML, CSS, and JavaScript**, designed to highlight projects and personal branding.

### 🎨 Theme
Elegant **black + blue** color palette for a sleek, futuristic tone.

### 🛠 Tech Stack
- HTML5  
- CSS3 (variables, flexbox)  
- JavaScript (ES6)  
- Hosted via [Vercel](https://vercel.com)
